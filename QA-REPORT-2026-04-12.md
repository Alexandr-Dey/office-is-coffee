## Критичные баги (P0)

### BUG-1: DrinkDetail модалка на весь viewport
- **Страница:** /menu → клик по напитку
- **Проблема:** Модалка использует `fixed inset-0` без ограничения max-width. На десктопе она растягивается от 0 до 1862px — за пределы 480px контейнера приложения.
- **Ожидание:** Модалка должна быть 480px и центрирована, как основной контейнер.
- **Файл:** `src/app/menu/page.tsx`, строка 139
- **Статус фикса:** Исправлено в локальном коде (добавлено `mx-auto max-w-[480px] left-0 right-0`)

### BUG-2: FAB кнопка корзины невидима на десктопе
- **Страница:** /menu (при наличии товаров в корзине)
- **Проблема:** Кнопка рендерится на координатах left=1776 — за правым краем viewport (1568px). Причина: `style={{ maxWidth: "calc((480px - 100%) / 2 + 100% - 16px)" }}` — формула ломается когда 100% > 480px.
- **Ожидание:** Кнопка всегда внутри 480px контейнера, видима.
- **Файл:** `src/app/menu/page.tsx`, строка 785
- **Статус фикса:** Исправлено в локальном коде (заменено на `right: max(16px, calc(50% - 224px))`)

### BUG-3: Push-токены не сохраняются у 71% пользователей
- **Страница:** все (push-система)
- **Проблема:** Из 7 клиентов в Firestore только 2 имеют push-токен. Функция `requestPushPermission()` вызывается только в 3 точках (onboarding, profile, order) и не обрабатывает ошибки / не делает retry. При сбое — пользователь навсегда без push.
- **Ожидание:** Push-токен автоматически обновляется при каждом визите.
- **Файл:** `src/lib/push.ts`
- **Статус фикса:** Исправлено (добавлена `ensurePushToken()`, вызывается на /menu при каждом визите)

### BUG-4: icon-192.png и icon-512.png отсутствуют (404)
- **Страница:** все (PWA manifest, push notifications)
- **Проблема:** `manifest.json` ссылается на иконки, которых нет в `/public/`. Push-уведомления приходят без иконки, PWA не устанавливается корректно.
- **Подтверждено:** GET /icon-192.png → 404
- **Статус фикса:** Исправлено (созданы обе иконки — зелёная чашка в brand-цвете)

## Высокие баги (P1)

### BUG-5: Одинаковый фон body и контейнера
- **Страница:** все
- **Проблема:** И `body`, и 480px контейнер используют `bg-brand-bg`. На десктопе контейнер визуально сливается с фоном — нет чёткой границы приложения.
- **Статус фикса:** Исправлено (`body` → `bg-neutral-100`, контейнер остаётся `bg-brand-bg`)

### BUG-6: Firestore Listen → 503 при навигации
- **Страница:** все (при переходе между страницами)
- **Проблема:** Real-time слушатели Firestore периодически получают 503 (Service Unavailable). Firebase автоматически переподключается, но это создаёт задержки в обновлении данных.
- **Влияние:** Среднее — Firestore recovers, но UX страдает при медленном соединении.
- **Статус:** Не исправлено (серверная проблема Firebase / quota)

### BUG-7: 0% open rate push-уведомлений
- **Страница:** /ceo → Push Analytics
- **Проблема:** Из 6 доставленных push — 0 открытий. Функция `trackPushOpened()` вызывается только на /menu, но `notificationclick` handler направляет на `/` с параметром `?pushId=XXX`. Если пользователь попадает на landing, а не на /menu — трекинг не срабатывает.
- **Статус:** Не исправлено (требует вызова `trackPushOpened` на всех страницах или в layout)

## Средние баги (P2)

### BUG-8: Огромное пустое пространство при скролле
- **Страница:** /menu (desktop)
- **Проблема:** При скролле вниз сцена уходит, и верхняя половина экрана становится пустым зелёным пространством. Контент 480px-контейнера прижат к низу viewport.
- **Влияние:** Визуальный дискомфорт на десктопе. На мобиле (основной target) — нормально.
- **Рекомендация:** Сцену можно сделать `sticky` сверху или уменьшить её высоту на десктопе.

### BUG-9: Отсутствует focus ring для keyboard navigation
- **Страница:** все
- **Проблема:** `outline-style: none` на кнопках. Пользователи с клавиатурой не видят фокус.
- **Рекомендация:** Добавить `focus-visible:ring-2 focus-visible:ring-brand-mint` на интерактивные элементы.

### BUG-10: VAPID key не задан
- **Контекст:** `NEXT_PUBLIC_FIREBASE_VAPID_KEY` в .env
- **Проблема:** Без VAPID key функция `getToken()` не может получить FCM-токен. В `push.ts` стоит проверка с `console.warn`, но пользователь ничего не видит.
- **Статус:** Требует ручной настройки в Firebase Console → Cloud Messaging → Web Push certificates

4. **Deploy** — `git add . && git commit && git push` для деплоя исправлений на Vercel
